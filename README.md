# Disaster-Rescue-Equipment-System
A Python Based Programme For Disaster Assessment And Rescue Equipment System
1. Project Overview
The Disaster Assessment and Rescue Equipment System is a python-based console application designed to recommend rescue equipment based on the type and severity of a disaster.

The System allows the user to:
1) Select a disaster type
2) Select the severity level of the disaster
3) View recommended rescue equipment
4) View an emergency checklist
5) Browse equipment according to different categories

The System supports the following disasters:
1) Flood
2) Earthquake
3) Tsunami
4) Cyclone
5) Drought
6) Landslide

The severity levels are:
1) High
2) Mid
3) Low

2. Features
Disaster Assessment
The user can select a disaster and its severity level. The system then displays the recommended equipment.

Emergency Checklist 
The system provides a general emergency checklist containing important items such as first-aid supplies , drinking water , emergency food , flashlights and communication devices.

Equipment Categories
The equipment is divided into four categories:
1) Medical Equipment
2) Communication Equipment
3) Safety Equipment
4) Rescue Equipment

Exit
The user can safely exit the program through the exit option.
