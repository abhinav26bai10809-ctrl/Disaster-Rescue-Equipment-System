# Disaster Assessment and Rescue Equipment System
1) Problem Statement
During a disaster, selecting suitable rescue equipment according to the type and severity of the disaster can be difficult. This project provides a simple python-based system that recommends suitable equipment based on the selected disaster and severity level.

2) Objective
The main objective of this project is to provide a simple and easy to use system for identifying recommended rescue equipment for different disaster.

3) Disasters Covered
Flood
Earthquake
Tsunami
Cyclone
Drought
Landslide

4) Severity Levels
High
Mid
Low

5) Main Features
Disaster and severity based equipment recommendations
Emergency Checklist
Equipment Categories
Exit Option

6) Conclusion
The project demonstrates how basic python concepts such as conditional statements, loops, lists, tuples, and user input can be used to create a simple disaster assessment and rescue equipment recommendation system.
